{{- /* Renders page body content, fixing a whitespace artifact. (Links: render-link.html emits no whitespace after , so a link followed by punctuation needs no fix here.) The seatable-icon shortcode emits a trailing newline after its , which collapses with the space the author types before the column name into a single rendered space. That space is a legal break point, so the icon can end up alone at the end of a line with its column name on the next one. We replace it with a non-breaking space, so icon + first word stay together (the rest of a multi-word name can still wrap normally). Fires when text or an opening tag follows (e.g. an icon in front of a bold column name); an icon followed by a CLOSING tag is left alone, so no stray space is added at the end of a paragraph or cell. Input: the page's .Content */ -}} {{- $c := . -}} {{- $c = replaceRE `(]*dtable-font[^>]*>)\s+([^<\s]|<[^/])` "${1} ${2}" $c -}} {{- $c | safeHTML -}}
