    - name: faq
      weight: 12
      title: 'Часто задаваемые вопросы о SeaTable в вузах и науке'
      items:
          - q: 'Для чего вузы могут использовать SeaTable?'
            a: 'SeaTable – это no-code база данных, которая подходит для научных проектов, заявок, организации экзаменов, учёта инвентаря, мероприятий и ИТ-поддержки. Подразделения сами создают приложения без программирования.'
          - q: 'Заменяет ли SeaTable систему управления вузом?'
            a: 'Нет. SeaTable не является системой управления вузом для зачисления или учёта успеваемости. SeaTable дополняет существующие системы там, где сегодня используются таблицы Excel и электронная почта, и подключается через API.'
          - q: 'Могут ли вузы использовать SeaTable в соответствии с GDPR?'
            a: 'Да. SeaTable Cloud работает у швейцарского провайдера Exoscale в сертифицированных центрах обработки данных в Германии. Кроме того, с SeaTable Server вы можете использовать платформу на собственной инфраструктуре.'
          - q: 'Можно ли подключить SeaTable к единой системе входа вуза?'
            a: 'Да. SeaTable Cloud поддерживает SAML 2.0 в подписке Enterprise. SeaTable Server поддерживает, в частности, SAML, OAuth, Shibboleth, Active Directory и LDAP.'
          - q: 'Можно ли связать SeaTable с R?'
            a: 'Да, через REST API SeaTable. Скрипты R могут получать данные по HTTP и записывать результаты обратно. Официального пакета для R нет, достаточно HTTP-пакета, например httr2. Скрипты выполняются в вашей собственной среде R, а не в SeaTable.'
          - q: 'Есть ли скидки для вузов и научных организаций?'
            a: 'Образовательные и государственные учреждения могут получить скидки на платные подписки. Вот как подать [заявку на скидку]({{< relref "help/teamverwaltung/abonnement/rabatte" >}}).'
          - q: 'Подходит ли SeaTable для управления библиографией?'
            a: 'Да, для общих подборок источников, связанных с проектами. Какие есть специализированные программы, показывает наше [сравнение программ для управления литературой]({{< relref "posts/literaturverwaltung" >}}).'
