            text: 'The R script connects using an access key (API token) that is valid for this one base only. It retrieves exactly the data needed for the analysis, always up to date. Manual CSV exports are no longer necessary.'

            text: 'Data preparation, models and charts are created in R, for example with `dplyr` and `ggplot2`. The script runs in the institute''s own environment and can be run again with new data at any time.'
          - headline: '4. Write results back'
            text: 'The script writes key figures such as means or effect sizes to a separate results table. This requires an API token with write permission; read access is sufficient for retrieving data only.'
          - headline: '5. Share results'
            text: 'Project partners see the key figures in a SeaTable app as a table or chart, without using R themselves and without access to the raw data.'

    - name: faq

      title: 'Frequently asked questions about SeaTable in higher education and research'
      items:
          - q: 'What can universities use SeaTable for?'
            a: 'SeaTable is a no-code database suited to research projects, applications, exam administration, inventory, events and IT support. Departments build their own applications without programming.'
          - q: 'Does SeaTable replace a campus management system?'
            a: 'No. SeaTable is not a campus management system for enrollment or academic records. It complements existing systems where Excel lists and emails are used today and can be connected via the API.'
          - q: 'Can universities use SeaTable in compliance with the GDPR?'
            a: 'Yes. SeaTable Cloud runs with the Swiss provider Exoscale in certified data centers in Germany. Alternatively, with SeaTable Server you run the platform on your own infrastructure.'
          - q: 'Can SeaTable be connected to the university''s central login?'
            a: 'Yes. SeaTable Cloud supports SAML 2.0 in the Enterprise subscription. SeaTable Server supports SAML, OAuth, Shibboleth, Active Directory and LDAP, among others.'
          - q: 'Can SeaTable be connected to R?'
            a: 'Yes, via the SeaTable REST API. R scripts can retrieve data over HTTP and write results back. There is no official R package; an HTTP package such as httr2 is sufficient. The scripts run in your own R environment, not in SeaTable.'
