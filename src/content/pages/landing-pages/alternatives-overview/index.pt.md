    - name: faq

      title: Perguntas frequentes sobre alternativas
      items:
          - q: Para que ferramentas é o SeaTable uma alternativa?
            a: O SeaTable é uma alternativa a ferramentas de bases de dados e folhas de cálculo como o Airtable, o Excel e o Google Sheets, a ferramentas de projetos e listas como o Asana, o Microsoft Lists e o Notion, e a software especializado como o Personio para RH e o HubSpot para CRM. A base é uma base de dados no-code que se utiliza como uma folha de cálculo.
          - q: O que distingue o SeaTable das outras ferramentas?
            a: O SeaTable combina base de dados relacional, automações, criador de apps e IA num só sistema. O SeaTable Cloud funciona em centros de dados na Alemanha e, com o SeaTable Server, também pode utilizar o SeaTable na sua própria infraestrutura.
          - q: O SeaTable está em conformidade com o RGPD?
            a: Sim. O SeaTable Cloud funciona no fornecedor suíço Exoscale, em centros de dados com certificação ISO 27001 na Alemanha. Os seus dados não saem da Europa. Se precisar do máximo controlo, pode alojar o SeaTable por conta própria.
          - q: Posso transferir os meus dados existentes?
            a: Sim. Pode importar dados existentes como ficheiro XLSX ou CSV. Para as bases do Airtable existe uma importação própria.
          - q: O SeaTable é gratuito?
            a: 'O SeaTable oferece uma subscrição Free gratuita e permanente. Para equipas maiores e funções avançadas existem subscrições pagas. Encontra todos os detalhes na [página de preços]({{< relref "pages/prices" >}}).'
          - q: Quando é que o SeaTable não é a alternativa certa?
            a: 'O SeaTable não é a melhor escolha para todas as equipas. O Airtable, por exemplo, oferece mais tipos de coluna e, opcionalmente, suporte empresarial com tempos de resposta garantidos por contrato.'
