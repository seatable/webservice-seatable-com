    - name: faq

      title: 'FAQ – No-Code App Builder de SeaTable'
      items:
          - q: 'Avec quel outil pouvons-nous créer des applications internes basées sur nos données, sans développeurs ?'
            a: 'Il existe trois approches : des app builders qui s''appuient sur une source de données existante (par exemple Softr sur Airtable, Glide ou AppSheet sur Google Sheets, Power Apps sur Microsoft 365), des outils pour développeurs comme Retool pour des bases de données SQL existantes – ou une plateforme qui réunit base de données et application, comme SeaTable. SeaTable convient si vos données se trouvent encore dans Excel ou dans des listes dispersées, si vous souhaitez vous passer de programmation et réunir données, automatisations et application dans un seul outil, avec hébergement en Allemagne ou sur vos propres serveurs.'
          - q: 'Comment transformer des listes Excel en une application dans laquelle chaque personne ne voit que ses propres entrées ?'
            a: 'Importez les listes sous forme de tables dans SeaTable et ajoutez une colonne de type Collaborateur qui indique à qui appartient une entrée. Dans l''App Builder, créez une page Tableau et définissez un filtre prédéfini sur cette colonne avec la condition « inclut l''utilisateur actuel ». Chaque personne ne voit alors que ses propres entrées dans l''application. Avec les autorisations de page (à partir de l''abonnement Enterprise), vous définissez en plus qui peut voir et modifier quelles pages.'
          - q: 'SeaTable est-il une alternative à Softr ou Glide ?'
            a: 'Oui, si vous souhaitez réunir base de données et application dans un seul outil. Softr et Glide excellent à transformer rapidement une source de données existante en application, Glide surtout pour les applications mobiles. Avec SeaTable, vous n''avez pas besoin d''une deuxième source de données : tables, liens, automatisations et application se trouvent sur une seule plateforme, avec une gestion des droits commune.'
          - q: 'Des personnes sans compte SeaTable peuvent-elles utiliser l''application ?'
            a: 'Oui. Vous pouvez partager une application publiquement, de sorte que toute personne disposant du lien puisse l''utiliser sans se connecter, ou créer un lien d''invitation avec un rôle et un mot de passe facultatif. Aucun compte utilisateur n''est nécessaire pour utiliser des applications publiques. Les personnes qui doivent saisir ou modifier des données dans l''application se connectent.'
          - q: 'Combien coûte le No-Code App Builder ?'
            a: 'L''App Builder est inclus dans tous les abonnements, y compris SeaTable Free pour jusqu''à 25 membres d''équipe. Les autorisations par page et par rôle sont disponibles à partir de l''abonnement Enterprise. Vous trouverez les prix actuels sur notre [page des tarifs]({{< relref "pages/prices" >}}).'
          - q: 'Puis-je publier mon application dans l''App Store ?'
            a: 'Non. Les applications SeaTable sont des applications web qui fonctionnent dans le navigateur – y compris sur smartphone et tablette. Si votre application doit apparaître dans l''App Store ou sur Google Play, un outil pour applications natives est un meilleur choix. Des applications SeaTable natives pour iOS et Android, qui vous permettent d''utiliser vos bases en mobilité, ont été annoncées.'
          - q: 'Où sont stockées les données de l''application ?'
            a: 'L''application n''a pas de données propres, elle affiche les données de votre base. SeaTable Cloud les stocke dans les centres de données d''Exoscale à Francfort et Munich ; vous concluez l''accord de sous-traitance (DPA) en ligne. Vous pouvez aussi exploiter [SeaTable Server]({{< relref "pages/product/seatable-server" >}}) sur vos propres serveurs.'
