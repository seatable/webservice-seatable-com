С выходом версии 7.0 SeaTable делает большой шаг вперёд в области искусственного интеллекта. Особенно выделяются две новинки: в конструкторе приложений теперь можно создавать страницы HTML с помощью ИИ, просто описав, что должна делать страница и как она должна выглядеть. А плагин «Чат ИИ», представленный как бета-версия в SeaTable 6.1, теперь готов к промышленному использованию. Обе функции работают на базе более мощной модели ИИ, которая в SeaTable Cloud выполняется на инфраструктуре нашего партнёра Exoscale.

Но SeaTable 7.0 — это не только ИИ. SDK для страниц HTML, который используют и страницы, созданные ИИ, получает четыре улучшения, о которых просили наши пользователи. В автоматизациях появляются два новых действия для связанных записей, а два существующих действия становятся более универсальными. Кроме того, релиз содержит многочисленные исправления ошибок и улучшения безопасности, которые снижают непосредственный риск, исходящий от ботов на базе ИИ и автоматически создаваемых эксплойтов. Дополняют релиз небольшие улучшения форм, статистики и двухфакторной аутентификации. А одна функция уходит на покой: новые приложения для запросов данных больше создавать нельзя, но существующие продолжают работать.

Сегодня утром мы обновили SeaTable Cloud до версии 7.0. Мы рекомендуем всем администраторам систем с самостоятельным размещением последовать нашему примеру, не в последнюю очередь из-за улучшений безопасности. Docker-образ SeaTable 7.0 доступен для загрузки на [Docker Hub](https://hub.docker.com/r/seatable/seatable-enterprise/). Как всегда, полный список изменений Вы найдёте в [журнале изменений]({{< relref "pages/changelog" >}}#release-7).

## Создание страниц HTML с помощью ИИ

SeaTable 7.0 позволяет создавать страницы HTML прямо в конструкторе приложений с помощью чата с ИИ. Опишите на естественном языке, что должна делать страница и как она должна выглядеть, и ИИ создаст её для Вас. Для создания страницы ИИ использует SDK SeaTable для страниц HTML (подробнее об SDK — в следующем разделе). Поэтому страница, созданная ИИ, может быть такой же функциональной, как и написанная вручную.

Начать очень просто: нажмите на значок «AI» на левой панели. Мастер проведёт Вас через настройку: задайте название проекта, выберите стиль интерфейса, определите источники данных и права доступа страницы и опишите нужную страницу. После этого ИИ создаст первую версию и покажет её в режиме предварительного просмотра. Затем Вы дорабатываете страницу в диалоге с ИИ, пока она не будет делать именно то, что Вам нужно. Одним нажатием на кнопку «Опубликовать» страница добавляется в Ваше приложение SeaTable.

![Создание страницы HTML с помощью ИИ в SeaTable 7.0](AI-generated_HTML_page.png)

Чат сохраняет всю беседу вместе с каждой версией страницы. Поэтому Вы можете в любой момент продолжить с того места, где остановились, или вернуться к более ранней версии, если изменение оказалось неудачным. Беседы и неопубликованные страницы хранятся 365 дней. А если Вы предпочитаете доработать страницу самостоятельно, её можно скачать и отредактировать вручную.

Если Вам интересно, что происходит за кулисами, нажмите на ссылку «Ход рассуждений» в чате. Для каждого шага там отображаются системный промпт, Ваш ввод и результат, возвращённый ИИ. В разделе статистики дополнительно указаны время и количество токенов, потраченных на этот шаг.

![Ход рассуждений ИИ в чате с ИИ](Thought_process_AI_chat.png)

В SeaTable Cloud генерация страниц выполняется на мощной модели с открытыми весами, размещённой у нашего инфраструктурного партнёра Exoscale, который также управляет серверами SeaTable Cloud. Поэтому Ваши промпты и схемы баз не обрабатываются никакими другими третьими сторонами. Данные, хранящиеся в Ваших базах, вообще никогда не передаются модели ИИ. При самостоятельном размещении можно использовать облачную модель одной из ведущих ИИ-лабораторий или подключить самостоятельно размещённую модель по своему выбору. SeaTable поддерживает все LLM с конечной точкой, совместимой с OpenAI.

{{< warning headline="Обновлённая инфраструктура ИИ" >}}
В основе генерации страниц HTML лежит модель Qwen 3.8 27B — мультимодальная большая языковая модель с 27 миллиардами параметров, разработанная Alibaba. Она предназначена для сложных рассуждений, программирования, исследований, обработки документов и сложных многошаговых задач и распространяется по лицензии Apache 2.0. Кроме того, Qwen 3.8 27B заменяет модель с открытыми весами [Gemma 4 E4B от Google DeepMind]({{< relref "posts/seatable-releases/seatable-release-6-0" >}}), которая до сих пор обеспечивала работу автоматизированных действий ИИ в SeaTable.
{{< /warning >}}

## Улучшенный SDK для страниц HTML

SDK SeaTable для страниц HTML связывает Ваши индивидуальные страницы с данными Вашей базы — как написанные Вами, так и созданные ИИ. С учётом отзывов пользователей в SeaTable 7.0 появились четыре улучшения, которые делают его значительно мощнее.

Во-первых, SDK теперь работает с именами пользователей. Раньше он мог только считывать данные строк из базы и не имел возможности получать имена, поэтому страницы могли показывать лишь внутренние имена пользователей вида `a1b2c3…@auth.local`. Теперь на Ваших страницах сразу видно, кто есть кто.

Во-вторых, SDK может определить вошедшего в систему пользователя. Раньше страница не могла узнать, кто её просматривает. С помощью нового метода `getCurrentUser()` страницы могут фильтровать данные по текущему пользователю, например показывать каждому участнику команды только его собственные задачи.

В-третьих, в SDK появились новые методы для добавления и удаления отдельных ссылок в колонках ссылок. Раньше метод `updateRow()` мог обновить колонку ссылок только целиком, заменяя все существующие ссылки. Новые методы позволяют легко добавить задачу в проект, включить позицию в коммерческое предложение или удалить участника из семинара, не затрагивая остальные ссылки.

В-четвёртых, SDK поддерживает три новых действия: отправка электронного письма, отправка уведомления и запуск скрипта. С их помощью страницы HTML могут отправлять сообщения и запускать скрипты нажатием кнопки, например подтверждать бронирование по электронной почте прямо со страницы. Учётные записи электронной почты и скрипты, которые Вы хотите использовать, должны быть настроены в базе.

![Три новых действия на страницах HTML: отправить электронное письмо, отправить уведомление и запустить скрипт](Action_permissions_HTML_page.png)

## Плагин «Чат ИИ» готов к промышленному использованию

Плагин «Чат ИИ» был представлен как бета-функция в [SeaTable 6.1]({{< relref "posts/seatable-releases/seatable-release-6-1" >}}). Он позволяет редактировать и анализировать базы на естественном языке: создавать записи, изменять значения, связывать строки или анализировать данные на русском, английском, немецком, французском и других языках. (Изменения схемы базы не поддерживаются.)

С выходом SeaTable 7.0 плагин покидает стадию бета-версии. С учётом отзывов пользователей мы улучшили как сам плагин, так и используемый им сервер MCP. Запросы теперь выполняются значительно эффективнее, что существенно снижает расход токенов. Мы также обновили список поддерживаемых облачных моделей ИИ.

Плагином также стало намного проще пользоваться. На стадии бета-версии нужно было указывать собственный API-токен для поддерживаемой LLM. В SeaTable Cloud плагин теперь по умолчанию использует нашу собственную модель ИИ, размещённую в Exoscale. Израсходованные токены конвертируются в кредиты ИИ и списываются с Вашего баланса кредитов ИИ: 1 миллион входных токенов равен 500 кредитам ИИ, а 1 миллион выходных токенов равен 1500 кредитам ИИ. Если Вы не хотите использовать модель по умолчанию, можно выбрать одну из других поддерживаемых моделей ведущих ИИ-лабораторий.

{{< warning headline="Скоро для систем с самостоятельным размещением" >}}
Плагин «Чат ИИ» сейчас доступен только клиентам SeaTable Cloud и SeaTable Dedicated. В ближайшие месяцы мы сделаем плагин доступным и для систем с самостоятельным размещением.
{{< /warning >}}

## Улучшенные правила автоматизации

SeaTable 7.0 приносит два новых действия автоматизации, делает два существующих действия более универсальными и добавляет больше подробностей в журнал автоматизации.

Первое новое действие, «Добавить запись в связанную таблицу», работает во многом так же, как и существующее действие «Добавить запись в другую таблицу»: оно создаёт новую запись в другой таблице. Кроме того, оно связывает новую запись с записью, которая запустила автоматизацию. Второе новое действие, «Изменить связанную запись в другой таблице», дополняет первое: оно изменяет существующие связанные записи в других таблицах. Например, при изменении статуса записи все зависимые связанные записи могут быть обновлены немедленно. Оба новых действия доступны с триггером «Когда строка обновляется».

![Новое действие автоматизации для связанных записей в SeaTable 7.0](New_automated_actions.png)

Действие «Преобразование страницы в PDF» создаёт PDF на основе шаблона дизайна страницы и сохраняет его в файловой колонке. В SeaTable 6.x оно было доступно только с триггером по расписанию. Теперь его можно использовать со всеми триггерами, имеющими контекст строки: «Когда строка обновляется», «Когда строка добавляется» и «В заданное время по условию». Это открывает путь к полностью автоматизированным рабочим процессам. Например, клиент отправляет запрос коммерческого предложения, SeaTable создаёт предложение (с помощью ИИ или без неё), и оно отправляется клиенту по электронной почте.

Действие «Управлять встречами в Календаре Google» теперь также может удалять встречи из календаря.

Наконец, журнал автоматизации стал более информативным: помимо времени срабатывания, теперь в нём также фиксируется время окончания выполнения.

## И многое другое

Многостраничные формы теперь могут отображать индикатор выполнения, чтобы респонденты видели, какая часть уже пройдена. Кроме того, сообщения после отправки формы теперь поддерживают форматированный текст.

Статистика в приложениях SeaTable перестроена на основе D3.js — широко используемой и мощной библиотеки JavaScript для визуализации данных. Это техническое изменение открывает путь к более настраиваемым диаграммам в будущем. Статистика в базе последует в следующем минорном релизе.

При настройке двухфакторной аутентификации SeaTable теперь показывает секретный ключ, чтобы Вы могли сохранить его в своём менеджере паролей.

И ещё кое-что: нативные приложения SeaTable для iOS и Android скоро появятся. Финальное тестирование уже идёт. Следите за новостями!

## Удалённая функция: приложения для запросов данных

В SeaTable 7.0 мы удалили конструктор приложений для запросов данных. Создавать новые приложения этого типа больше нельзя. На существующие приложения для запросов данных это не влияет, и они продолжают работать в обычном режиме.

Для новых приложений используйте универсальные приложения. Они могут предоставлять те же функции, что и приложения для запросов данных, и даже больше. О том, как их создавать, Вы узнаете на [страницах справки об универсальных приложениях]({{< relref "help/app-builder/seitentypen-in-universellen-apps/ueberblick" >}}).
