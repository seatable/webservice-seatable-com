С помощью автоматизаций вам больше не придется блокировать строки в таблицах вручную, вы можете выполнять [блокировку строк]({{< relref "help/base-editor/zeilen/sperren-einer-zeile" >}}) автоматически. Это очень полезно, если вы всегда хотите предотвратить дальнейшее редактирование строки после определенного момента времени (например, когда операция завершена).

![Блокировка строки с помощью автоматизации](images/lock-row-with-an-automation.png)

{{< warning  headline="Разблокировка возможна только вручную" text="Вы **не можете** **разблокировать** строки, заблокированные с помощью автоматизации, таким же образом. Это возможно только вручную и при наличии необходимых **прав администратора**." />}}

## Создание автоматизации

1. В опциях базы нажмите на {{< seatable-icon icon="dtable-icon-rule" >}}, а затем на **Правила автоматизации**.
2. Нажмите кнопку **Добавить правило**.
3. **Назовите** автоматизацию и определите **таблицу** и **вид**, в которых она должна работать.
4. Определите **триггерное событие**, которое запускает автоматизацию.
5. Нажмите **Добавить действие** и выберите **Заблокировать запись** в качестве автоматического действия.

![Выбор автоматического действия: "Заблокировать запись"](images/lock-record.png)

6. Подтвердите с помощью кнопки **Отправить**.

{{< warning headline="Важное замечание" >}}

Автоматическое действие **Заблокировать запись** доступно только для следующих триггерных событий:

- Когда строка обновляется
- Когда строка добавляется
- В заданное время по условию

{{< /warning >}}

## Пример применения

Например, если вы хотите **заблокировать** каждую строку в одной из ваших таблиц, в которой определенная запись достигает конкретного **значения**, задайте событие **Когда строка обновляется** в качестве триггера автоматизации.

![Определение триггерного события автоматизации](images/trigger-example-1.png)

Затем задайте **значение** и **столбец**, в котором оно должно быть достигнуто.

![Определение триггерного события автоматизации](images/trigger-example-2.png)

Наконец, установите **Заблокировать запись** в качестве автоматического действия.

![Определение автоматического действия](images/automated-action-example.png)

С этого момента созданная автоматизация будет блокировать **все строки**, в которых **записи** изменяются таким образом, что они удовлетворяют правилу автоматизации.

![Заданное автоматическое действие: "Заблокировать запись"](images/automated-action-example-2.png)

{{< warning  headline="Обратите внимание"  text="С помощью автоматизации вы можете блокировать только те строки, в которых произошло триггерное событие автоматизации. Правило автоматизации по схеме **Событие в строке X вызывает блокировку строки Y** невозможно." />}}

## Одновременная блокировка нескольких строк

Автоматизации чрезвычайно полезны, если вы хотите заблокировать несколько строк одновременно. Для этого выберите триггер **В заданное время по условию**, и задайте соответствующие условия. Вместо того чтобы устанавливать частоту и время выполнения, нажмите кнопку **Выполнить сейчас** внизу, чтобы немедленно заблокировать все нужные строки.

Для получения дополнительной информации о блокировке строк см. статью [Блокировка строки]({{< relref "help/base-editor/zeilen/sperren-einer-zeile" >}}).
