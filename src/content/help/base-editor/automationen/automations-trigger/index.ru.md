**Триггерные события** – это один из двух основных компонентов автоматизаций. События вызывают различные типы [действий]({{< relref "help/base-editor/automationen/automations-aktionen" >}}), которые вы можете определить индивидуально для каждой автоматизации. В этой статье вы получите **обзор** различных типов триггеров.

## Доступные триггеры автоматизации

В последней версии SeaTable существует в общей сложности **четыре** различных триггера на выбор:

![Доступные на данный момент триггеры](images/automation-triggers.jpg)

- Когда строка обновляется
- Когда строка добавляется
- В заданное время
- В заданное время по условию

## Настройки триггера

Чтобы создать или отредактировать триггер, нажмите на соответствующее поле в центральной области редактора автоматизации. Настройки триггера появятся справа.

![Настройки триггера](images/automation-trigger-settings.jpg)

- Сначала вы можете изменить **триггер** с помощью выпадающего меню. Для этого выберите нужное триггерное событие.
- Затем определите **таблицу** и **вид**, в которых должна действовать автоматизация.
- В зависимости от типа триггера, вы можете задать дополнительные настройки, например, **контролируемые столбцы**, **условия** для срабатывания или **время** срабатывания.

![Настройки триггера в деталях](images/automation-trigger-settings.gif)

{{< warning headline="Сохраните изменения" text="Не забудьте **сохранить** настройки триггера! Иначе все изменения будут потеряны, когда вы закроете окно." />}}

## Триггер автоматизации: Когда строка обновляется

Если вы выберете это событие в качестве триггера, соответствующая автоматизация будет срабатывать каждый раз, когда в одном из контролируемых столбцов изменяется значение, а строка в выбранном виде после редактирования удовлетворяет определенным условиям. Если вы хотите, чтобы триггер срабатывал каждый раз, когда происходит изменение, не добавляйте никаких условий.

В **условиях** вы можете определить отдельно для каждого столбца, как должно выглядеть соответствующее значение после редактирования, чтобы запустилась автоматизация. Кроме того, вы можете решить, все или только выбранные столбцы вида должны отслеживаться на предмет наступления триггерного события.

![Настройки триггера при изменении строки](images/automation-trigger-when-a-row-is-updated.jpg)

Если вы выбрали это событие в качестве триггера для автоматизации, вы можете выбрать одно из следующих **автоматических действий**:

- Отправить уведомление
- Отправить уведомление приложения
- Отправить электронное письмо
- Добавить запись
- Заблокировать запись
- Изменить запись
- Добавить ссылки
- Добавить запись в другую таблицу
- Добавить запись в связанную таблицу
- Изменить связанную запись в другой таблице
- Запустить скрипт Python
- Запустить AI (искусственный интеллект)
- Управлять встречами в Календаре Google
- Преобразование страницы в PDF

## Триггер автоматизации: Когда строка добавляется

Если вы выберете это событие в качестве триггера, соответствующая автоматизация будет срабатывать каждый раз, когда в выбранном виде добавляется **новая строка**. Кроме того, вы можете дополнительно ограничить наступление этого события, определив **условия**, которым должна удовлетворять новая строка.

![Настройки триггера при добавлении строки](images/automation-trigger-when-a-row-is-added.jpg)

В условиях вы можете указать отдельно для каждого столбца, каким должно быть соответствующее значение, чтобы запустилась автоматизация. Если вы хотите, чтобы каждая новая строка запускала автоматизацию, не добавляйте никаких условий.

{{< warning headline="Совет" text="Этот триггер особенно полезен, например, когда вы импортируете новые записи данных или вводите их через формы." />}}

Если вы выберете это событие в качестве триггера для автоматизации, вы сможете выбрать одно из следующих **автоматических действий**:

- Отправить уведомление
- Отправить уведомление приложения
- Отправить электронное письмо
- Добавить запись
- Заблокировать запись
- Изменить запись
- Добавить ссылки
- Добавить запись в другую таблицу
- Запустить скрипт Python
- Запустить AI (искусственный интеллект)
- Управлять встречами в Календаре Google
- Преобразование страницы в PDF

## Триггер автоматизации: В заданное время

Если вы выбрали этот триггер, вы можете определить **время**, в которое автоматизация будет выполняться **ежедневно**, **еженедельно** или **ежемесячно**.

![Настройка параметров для ежедневного триггера в заданное время](images/automation-trigger-at-scheduled-time.jpg)

Если для ежедневной автоматизации можно указать только **время**, то вы также можете указать **день недели** для еженедельной автоматизации или **календарный день** для ежемесячной автоматизации.

![Настройка параметров для еженедельного триггера в заданное время](images/automation-trigger-at-scheduled-time-weekly.jpg)

Если вы установили этот триггер для автоматизации, вы можете выбрать одно из следующих **автоматических действий**:

- Отправить уведомление
- Отправить уведомление приложения
- Отправить электронное письмо
- Добавить запись
- Добавить ссылки
- Запустить скрипт Python
- Запустить обработку данных
- Сгенерировать PDF из документа и отправить
- Архивировать

## Триггер автоматизации: В заданное время по условию

С помощью этого триггера вы, как и в предыдущем триггере, указываете **время**, в которое автоматизация срабатывает **ежедневно**, **еженедельно** или **ежемесячно**. Вы также можете ограничить круг строк, на которые распространяется это триггерное событие.

Для **условий** вы можете указать отдельно для каждого столбца, каким должно быть соответствующее значение, чтобы автоматизация была выполнена в указанное время.

![Триггер в заданное время для записей, удовлетворяющих определенным условиям](images/automation-trigger-at-scheduled-time-for-records-that-match-condition.jpg)

- Отправить уведомление
- Отправить уведомление приложения
- Отправить электронное письмо
- Заблокировать запись
- Изменить запись
- Преобразование страницы в PDF
- Архивировать
