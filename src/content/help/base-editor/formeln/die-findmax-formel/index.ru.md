**Формула Findmax** ищет **максимальное значение** среди записей связанного столбца и возвращает его. Это полезно, если в связанной таблице есть **несколько записей**, которые ссылаются на одну и ту же запись (например, о человеке или категории) в другой таблице.

## Для чего можно использовать формулу Findmax

Вы можете использовать формулу Findmax со всеми буквенно-цифровыми значениями для определения **максимального значения**. Допустим, вы используете SeaTable для [планирования бюджета]({{< relref "templates/finance/budget-plan" >}}), где в одной таблице хранятся расходы, а в другой – категории. Затем вы можете связать каждый расход с категорией. Чтобы узнать, каким был **самый высокий расход по каждой категории**, вы можете с помощью **формулы Findmax** отобразить наибольшее значение среди всех связанных расходов.

## Чтобы использовать формулу Findmax

### Добавить ссылку на таблицу

Информацию о том, как создать колонку типа **Связать с другими записями**, см. в статье [Колонка ссылок]({{< relref "help/base-editor/spaltentypen/die-verknuepfungsspalte" >}}). Это основное требование для того, чтобы иметь возможность использовать формулу Findmax.

{{< warning headline="Необходимо несколько связанных строк" >}}

Использование формулы Findmax имеет смысл только в том случае, если в настройках колонки ссылок отключена опция **Ограничить ссылки не более чем одной строкой**. Если бы опция была включена, формула Findmax всегда показывала бы то же значение, что и в единственной связанной строке.

{{< /warning >}}

### Добавить столбец с формулой Findmax

![формула findmax](images/findmax.gif)

1. Создайте новый столбец типа **Формула для ссылок**.
2. Установите параметр **Findmax** в качестве формулы.
3. Выберите ранее созданный столбец типа **Связь с другими записями** в этой таблице.
4. Теперь укажите **столбец поиска в связанной таблице**, запись которого с максимальным значением должна отображаться в столбце Findmax.
5. Выберите **столбец сравнения в связанной таблице**, в котором вы хотите определить максимальное значение.
6. Нажмите **Отправить**.
