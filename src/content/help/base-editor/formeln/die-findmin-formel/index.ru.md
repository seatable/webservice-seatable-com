**Формула Findmin** ищет **минимальное значение** среди записей связанного столбца и возвращает его. Это полезно, если в связанной таблице есть **несколько записей**, которые ссылаются на одну и ту же запись (например, о человеке или категории) в другой таблице.

## Для чего можно использовать формулу Findmin

Вы можете использовать формулу Findmin со всеми буквенно-цифровыми значениями для определения **минимального значения**. Допустим, вы используете SeaTable для [планирования бюджета]({{< relref "templates/finance/budget-plan" >}}), где в одной таблице хранятся расходы, а в другой – категории. Затем вы можете связать каждый расход с категорией. Чтобы узнать, каким был **самый низкий расход по каждой категории**, вы можете с помощью **формулы Findmin** отобразить наименьшее значение среди всех связанных расходов.

## Чтобы использовать формулу Финдмина

### Добавить ссылку на таблицу

Узнайте, как создать колонку типа **Ссылка на другие записи** в статье [Колонка ссылок]({{< relref "help/base-editor/spaltentypen/die-verknuepfungsspalte" >}}). Это основное требование для того, чтобы иметь возможность использовать формулу Findmin.

{{< warning headline="Необходимо несколько связанных строк" >}}

Использование формулы Findmin имеет смысл только в том случае, если в настройках колонки ссылок отключена опция **Ограничить ссылки не более чем одной строкой**. Если бы опция была включена, формула Findmin всегда показывала бы то же значение, что и в единственной связанной строке.

{{< /warning >}}

### Добавить столбец с формулой Findmin

![формула findmin](images/findmin.gif)

1. Создайте новый столбец типа **Формула для ссылок**.
2. Задайте в качестве формулы параметр **Findmin**.
3. Выберите ранее созданный столбец типа **Связь с другими записями** в этой таблице.
4. Теперь укажите **столбец поиска в связанной таблице**, запись которого с минимальным значением должна отображаться в столбце Findmin.
5. Выберите **столбец сравнения в связанной таблице**, в котором вы хотите определить минимальное значение.
6. Нажмите **Отправить**.
