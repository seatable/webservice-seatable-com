Формула Countlinks подсчитывает количество связанных записей столбца типа **Link с другими записями** в соответствующей строке.

{{< warning  headline="Связывание таблиц является основным требованием" >}}

Вы можете создать столбец с формулой Countlinks, только если вы связали две таблицы. О том, [как создать такую ссылку]({{< relref "help/base-editor/spaltentypen/die-verknuepfungsspalte" >}}).

{{< /warning >}}

## Сфера применения формулы Countlinks

**Формулу Countlinks** следует использовать всегда, когда вы хотите отобразить **количество записей, связанных со строкой**.

Например, при планировании семинара можно вывести количество зарегистрированных участников из отдельной таблицы. Таким образом, в [колонке ссылок]({{< relref "help/base-editor/spaltentypen/die-verknuepfungsspalte" >}}) будут записаны имена всех участников.

![Формула Countlinks.](images/countlinks-2.png)

Использование формулы Countlinks имеет смысл только в том случае, если в настройках колонки ссылок отключена опция **Ограничить ссылки не более чем одной строкой**. Если бы опция была включена, в поле формулы Countlinks всегда стояла бы единица (= одна-единственная связанная строка).

## Создание формулы подсчета ссылок

![Формула Countlinks.](images/countlink.gif)

1. Создайте новый столбец типа **Формула для ссылок**.
2. Дайте колонне подходящее **название**.
3. Установите параметр **Countlinks** в качестве формулы.
4. Теперь выберите **колонку ссылок**, записи которой вы хотите подсчитать, в поле **Выбрать** колонку ссылок в **этой таблице**.
5. Нажмите **Отправить**.
