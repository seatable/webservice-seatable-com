Для **предварительного заполнения веб-форм** у вас есть возможность задать значения по умолчанию в полях формы. Это можно сделать непосредственно в URL-адресе или с помощью удобной функции в SeaTable.

## Создание ссылки на форму со значениями по умолчанию в SeaTable

SeaTable предлагает функцию, с помощью которой вы можете легко создавать **ссылки на формы**, в которых значения по умолчанию уже заданы заранее.

1. Создайте [веб-форму]({{< relref "help/base-editor/webformulare/webformulare" >}}).
2. В редакторе веб-формы нажмите на кнопку {{< seatable-icon icon="dtable-icon-share" >}} **Поделиться** в правом верхнем углу.
3. Теперь нажмите на кнопку **Добавить ссылку на форму**, и появится следующее окно ввода:
   ![Предварительно заполненные значения в пользовательских ссылках на форму](images/Vorbefuellte-Werte-in-benutzerdefinierten-Formularlinks.png)
4. Дайте новой ссылке **имя**. В разделе **Пользовательский URL** вы можете самостоятельно задать часть URL-адреса.
5. Чтобы предварительно заполнить поле формы значением по умолчанию, нажмите на кнопку **Добавить поле**. Выберите **поле формы** из раскрывающегося меню и введите нужное **значение по умолчанию**.
6. Наконец, вы можете решить, можно ли изменить значение по умолчанию при заполнении формы. Для этого выберите **Чтение и запись**. Если вы выберете **Только чтение**, значение в форме изменить будет нельзя.
7. Нажмите кнопку **Создать**, чтобы сгенерировать ссылку.

![Пользовательская ссылка на форму с предварительно заполненным значением](images/Benutzerdefinierter-Formularlink-mit-vorausgefuelltem-Wert.png)

Результат, т. е. расширенный URL-адрес, такой же, как и при ручном способе, описанном ниже.

## Предварительное заполнение веб-формы непосредственно через URL-адрес

![Предварительное заполнение веб-формы](images/prefill.png)

1. Создайте [веб-форму]({{< relref "help/base-editor/webformulare/webformulare" >}}).
2. Нажмите на кнопку {{< seatable-icon icon="dtable-icon-share" >}} **Поделиться** в редакторе веб-формы, чтобы получить ссылку на веб-форму.
3. **Скопируйте** ссылку и вставьте ее в новой вкладке в **адресную строку браузера**, где вы сможете ее отредактировать и проверить.
4. Чтобы предварительно заполнить поле формы значением по умолчанию, добавьте к ссылке на форму строку **/?prefill_COLUMNNAME=PREFILLVALUE**.

Вместо **COLUMNNAME** укажите имя поля, которое вы хотите заполнить; вместо **PREFILLVALUE** укажите желаемое значение по умолчанию. Пробелы следует записывать как **%20**. Обращайте внимание на верхний и нижний регистр.

**Пример**: если вы хотите отправить Джо Смиту персонализированную веб-форму, в которой уже указано его имя, добавьте к ссылке на форму строку **/?prefill_Name=Joe%20Smith**.

Чтобы использовать **несколько значений по умолчанию**, объедините записи предварительного заполнения символом **&**: /?prefill_COLUMNNAME=PREFILLVALUE**&**prefill_COLUMNNAME=PREFILLVALUE

После этого вы можете проверить ссылку, нажав **клавишу Enter** и открыв веб-форму. Если все получилось, вы увидите в этом **предварительном просмотре** предварительно заполненные значения по умолчанию.
