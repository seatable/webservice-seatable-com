При создании **веб-форм** можно настроить так, чтобы определенные **поля** становились видимыми только после выполнения **условия** в предыдущем поле. Это позволяет улучшить **навигацию пользователя** при заполнении формы.

## Установка условия для поля формы

1. Откройте существующую **веб-форму**.
2. Нажмите на поле, чтобы открыть **настройки поля**.
3. Перейдите к пункту **Показывать поле только при выполнении условий** и нажмите на кнопку со значком плюса, с помощью которой можно **добавить условие**.
4. Выберите **предыдущее поле**, к которому должно относиться условие.
5. Затем задайте **условие**. В зависимости от типа базового столбца у вас есть разные варианты на выбор.

{{< warning  headline="Примечание"  text="Условное отображение доступно, только если есть хотя бы одно предыдущее поле." />}}

## Пример применения

![Условное отображение полей в веб-формах](images/Bedingte-Anzeige-von-Feldern-in-Webformularen.gif)

Допустим, вы хотите провести в своей компании опрос об удовлетворенности сотрудников. Например, вы хотите задать вопрос "Насколько вы удовлетворены нашим лизингом служебных автомобилей?", но знаете, что служебный автомобиль предоставляется только сотрудникам на руководящих должностях. Поэтому вы хотите задать этот вопрос только своим руководителям.

Для начала создайте [столбец рейтинга]({{< relref "help/base-editor/spaltentypen/die-rating-spalte" >}}) в таблице и добавьте его в качестве **поля** в веб-форму. Затем добавьте **условие**, что поле рейтинга будет отображаться только в том случае, если в предыдущем **поле выбора "Должность"** был выбран вариант "Head of" или "Team lead". Поле выбора должно быть **обязательным** для заполнения, так как в противном случае руководители, оставившие это поле пустым, тоже не увидят вопрос о лизинге служебных автомобилей.

Чтобы участники не могли увидеть скрытые поля формы, просто перебирая условия, вы можете вставить **разрывы страниц**. Тогда после заполнения обязательного поля участникам сначала нужно нажать **Следующая страница**, и там условные поля либо отобразятся, либо нет.
