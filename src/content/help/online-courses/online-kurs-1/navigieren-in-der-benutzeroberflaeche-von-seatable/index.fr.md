Commençons par regarder comment utiliser SeaTable. SeaTable est une solution web : vous l'utilisez simplement dans votre navigateur. Nous allons passer rapidement en revue les éléments de l'interface : à quoi servent les différentes icônes, et où trouver ce dont vous aurez besoin pour créer vos bases.

Ouvrez votre navigateur, rendez-vous sur la page de connexion de SeaTable et connectez-vous avec vos identifiants. La page d'accueil devrait ressembler à peu près à ceci :

![Éléments de la page d'accueil SeaTable](images/elements_seatable_homepage.png)

## La page d'accueil

La page d'accueil se divise en deux parties : la navigation à gauche et l'aperçu des bases à droite. Vous n'y voyez sans doute encore que peu de bases, voire aucune, mais cela va vite changer. Chaque base y est représentée par une tuile colorée, avec son nom à droite.

### Qu'est-ce qu'une base, au juste ?

Une base est une base de données. Elle se compose d'un ou de plusieurs tableaux et peut contenir plusieurs milliers de lignes. La page d'accueil affiche toutes les bases auxquelles vous avez accès, réparties en plusieurs espaces selon qui a créé la base ou qui y a accès :

- **Mes bases** : les bases que vous avez créées vous-même. Tant que vous ne les avez pas explicitement partagées avec une personne ou un groupe, vous êtes le seul à y avoir accès.
- **Favoris** : marquez n'importe quelle base comme favorite pour la retrouver toujours dans cette section.
- **Groupes** : SeaTable est fait pour travailler à plusieurs. Les groupes vous permettent de rendre une base accessible à toute une équipe.

## L'éditeur de base

Ouvrez maintenant l'une de vos bases en cliquant dessus. Si vous n'en avez pas encore, créez-en une : son nom n'a pas d'importance pour l'instant.

Votre base ne contient pour le moment que trois cellules vides. Rien d'inquiétant : pour expliquer les différents éléments, nous nous appuyons sur une base d'exemple déjà remplie.

![Éléments de la base SeaTable](images/elements_seatable_base.png)

Au premier abord, une base peut impressionner : les boutons et les possibilités ne manquent pas. Voyons ces éléments un par un.

### Tableaux

En haut de chaque base, ses tableaux s'affichent côte à côte sous forme d'onglets. Selon ce que vous connaissez déjà, vous pouvez les comparer aux feuilles de calcul d'Excel ou aux tables d'une base de données. Dans chaque tableau, vous créez les colonnes qui accueilleront vos informations. Mais alors que dans Excel toutes les colonnes se valent, SeaTable vous demande de choisir un type pour chaque nouvelle colonne. Ce type détermine ce que la colonne pourra contenir. Cela peut paraître compliqué, mais ça ne l'est pas :

- Une colonne de nombres n'accepte que des nombres, pas d'images.
- Une colonne de date n'accepte que des dates, pas de nombres.
- Une colonne de… – vous avez compris le principe.

### Lignes

Vos informations sont enregistrées dans les lignes d'un tableau, et chaque ligne correspond à un enregistrement. Si votre tableau `Expenses` compte 50 lignes, par exemple, vous y avez saisi 50 dépenses.

### Vues

Une vue est une manière d'afficher les lignes d'un tableau, que vous définissez vous-même : tris, filtres, regroupements, colonnes masquées et autres réglages.

Un tableau peut avoir une ou plusieurs vues, qui affichent toutes les mêmes données. Si vous modifiez une cellule dans une vue, c'est donc la donnée du tableau qui change, et la modification apparaît dans toutes ses vues.

Ce cours revient plus en détail sur les vues, à travers des exemples concrets.

## Résumé

Vous avez découvert les principaux éléments de l'interface de SeaTable. Ne vous laissez pas impressionner par toutes ses possibilités : dès la prochaine étape du cours, vous commencerez à construire votre propre **système de suivi des dépenses**, et découvrirez au passage de nombreuses fonctionnalités de SeaTable.
