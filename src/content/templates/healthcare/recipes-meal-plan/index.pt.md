    - name: "faq"

      title: "Perguntas frequentes sobre o modelo de cardápio do SeaTable"
      subtitle: 
      items:
      - q: "Posso usar o modelo de cardápio no celular durante as compras?"
        a: "Sim, você pode acessar seus dados pelo navegador do celular. A lista de compras mostra os ingredientes que faltam, e você marca os itens comprados na hora. Eles saem da visualização filtrada “needs to be bought”. Detalhes das receitas e datas planejadas também ficam acessíveis fora de casa."
      - q: "O programa gratuito para organizar receitas serve para dieta vegana ou keto?"
        a: "Sim, você pode criar categorias e opções de seleção para diferentes dietas. O campo “preferences” ajuda a documentar para quais pessoas e preferências um prato é adequado. Se um prato é de fato vegano, keto, sem glúten ou adequado para alergias, você mesmo deve verificar pelos ingredientes."
      - q: "O modelo de cardápio semanal soma os ingredientes para a lista de compras?"
        a: "O modelo vincula ingredientes a receitas e mostra os itens ainda não comprados em uma lista de compras filtrada. Não inclui a soma automática de ingredientes iguais de vários pratos nem o ajuste ao número de porções. Para isso, adicione a estrutura de dados, os cálculos ou as automações necessários."
      - q: "O SeaTable é gratuito para sempre para pessoas físicas e famílias?"
        a: "Para começar, há um plano gratuito do SeaTable. Se ele é suficiente para sua casa depende dos limites vigentes de usuários, dados e armazenamento, além das funções necessárias. Verifique o escopo atual do plano, principalmente antes de usar funções de IA ou automações adicionais."
      - q: "Como adiciono valores nutricionais ou modo de preparo ao modelo de cardápio?"
        a: "Você já pode registrar calorias e outros valores em “nutrition per serving”; as calorias estão vinculadas à tabela de receitas. Para o modo de preparo, “recipes” tem o campo de URL “instructions”. Para salvar instruções completas, adicione um campo de texto longo e, para fibras ou estoque, outras colunas."
