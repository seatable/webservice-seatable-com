    - name: "faq"
      weight: 20
      title: 'FAQ sur le modèle de répertoire des employés de SeaTable'
      subtitle:
      items:
      - q: 'Avec quel outil les petites entreprises créent-elles une base de données du personnel sans acheter un logiciel RH complet ?'
        a: 'Il existe trois options : une liste Excel ou SharePoint, le module du personnel d''une suite RH comme Personio, ou une base de données flexible comme SeaTable. SeaTable convient si les données du personnel, les départements et des processus comme les arrêts maladie ou l''intégration doivent être liés et si vous souhaitez définir vous-même les données que vous enregistrez. Avec ce modèle, vous démarrez immédiatement ; plus d''informations sur notre page [Processus RH]({{< relref "pages/landing-pages/industry-solutions/hr" >}}).'
      - q: 'Puis-je utiliser gratuitement le modèle de répertoire des employés ?'
        a: 'Oui, vous utilisez le modèle dans SeaTable Cloud avec SeaTable Free pour jusqu''à 25 membres d''équipe. Cela vaut aussi pour le modèle Gestion des arrêts maladie.'
      - q: 'Comment gérer les arrêts maladie dans le répertoire des employés ?'
        a: 'Il existe pour cela le modèle dédié [Gestion des arrêts maladie](https://cloud.seatable.io/copy-template/?template_link_token=66efdfd13de84a9a96a9). Le personnel se déclare malade via un formulaire web, les supérieurs reçoivent un e-mail par bouton, et les jours d''absence sont additionnés par personne. Les arrêts maladie électroniques officiels (comme l''eAU en Allemagne) restent récupérés via votre logiciel de paie ou RH ; le modèle sert à la vue d''ensemble interne.'
      - q: 'Le modèle remplace-t-il un dossier du personnel numérique ?'
        a: 'Pour beaucoup de petites équipes, il suffit comme base de données centrale du personnel. Les fonctions d''une suite RH comme la paie, les délais légaux de conservation et de suppression ou le libre-service pour les bulletins de salaire ne sont pas intégrées. Vous pouvez stocker des documents comme les contrats dans une colonne de fichiers ; les délais, vous les gérez vous-même avec des colonnes et des vues.'
      - q: 'Où les données du personnel sont-elles stockées ?'
        a: 'SeaTable Cloud stocke vos données dans des centres de données d''Exoscale à Francfort et à Munich. Vous concluez l''accord de sous-traitance (DPA) en ligne. Vous pouvez aussi exploiter SeaTable sur vos propres serveurs.'
      - q: 'Puis-je reprendre des listes du personnel existantes depuis Excel ?'
        a: 'Oui, vous importez les listes existantes dans le modèle via l''import CSV ou Excel, puis vous adaptez les colonnes, les départements et les vues.'
      - q: 'Quels modèles complètent le répertoire des employés ?'
        a: 'Pour les absences, utilisez la [gestion des congés]({{< relref "templates/human-resources/holiday-request-management" >}}) et le modèle [Gestion des arrêts maladie](https://cloud.seatable.io/copy-template/?template_link_token=66efdfd13de84a9a96a9), pour les heures de travail le [suivi du temps de travail]({{< relref "templates/human-resources/recording-working-time" >}}). Découvrez ce qu''un système d''information RH doit offrir dans notre guide [HRIS]({{< relref "posts/20250317-hris" >}}).'
