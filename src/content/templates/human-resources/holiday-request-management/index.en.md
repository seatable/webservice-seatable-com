      - q: "Can I use this template as software for vacation management in my company?"
        a: "Yes, the template is sufficient for many small and medium-sized teams. All you need is a free SeaTable account – with SeaTable Free for up to 25 team members – and you can start straight away. You map rules such as part-time work, carrying over remaining vacation days or public holidays by region yourself using columns and formulas; a connection to payroll is not built in. If you need all of this ready-made and maintained, an HR suite is the better choice."
      - q: "How does the database help me manage vacation requests and calculate remaining vacation days?"
        a: 'When you manage vacation requests, the template automatically links every request to the remaining vacation account of the respective employee. Formula columns calculate the remaining vacation entitlement in real time as soon as a request is approved – manual recalculation is no longer necessary.'
      - q: "Can I set up different access rights for employees and managers in absence management?"
        a: "Yes, in absence management you define granular permissions. In an app, a preset filter on the current user ensures that employees only see their own vacation requests, while managers and the HR department, for example, can view, edit and approve requests."
      - q: "Is using SeaTable for vacation management compliant with data protection law (GDPR)?"
